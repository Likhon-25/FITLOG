# Fit Intent Log

Fit Intent Log is a fitness and gym tracking web app that helps users discover gyms, save favorite gyms, and manage personalized workout routines in one place. It is designed to make fitness planning simple, organized, and motivating.

## Technologies Used

* Next.js
* TypeScript
* React
* Tailwind CSS
* JavaScript
* CSS Modules / Global CSS

## Key Features

1. **Gym Discovery & Details**
   Users can discover gyms and view detailed information about them.

2. **Favorite Gyms**
   Users can save their favorite gyms and access them later.

3. **Personalized Workout Planning**
   Users can create and manage personalized workout plans.

4. **Today's Plan**
   Users can manage and track their daily workout routine.

5. **Responsive & Modern UI**
   The application provides a clean, modern, and responsive interface for both desktop and mobile devices.
